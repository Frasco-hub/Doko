# Doko

Find. Evaluate. Invest.

Doko is an investor-first private-market intelligence platform for discovering, evaluating and comparing companies through evidence, analytics and valuation scenarios.

## Product direction
- Investor discovers companies rather than companies relying only on pitch outreach.
- Evidence-backed operating metrics.
- Transparent valuation scenarios.
- Investor criteria matching.
- Demo data only at this stage.

## Run
```bash
npm install
npm run dev
```

## Next build stages
1. Authentication and investor profiles.
2. Founder/company onboarding.
3. Evidence and data-source ingestion.
4. Real valuation engine with documented assumptions.
5. Investor watchlists and comparison.
6. Secure data rooms and introduction requests.
7. Backend/database and production deployment.
